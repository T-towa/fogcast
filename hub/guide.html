できること

全チャンネルターミナルごとの今の状態（作業中・承認待ち・入力待ち・終了）と、直近 60 分の番組表。
会話メッセージアプリのように、あなたの依頼は右、Claude の返答は左に。道具の呼び出しはその間にまとまり、ターンごとに畳めます。
操作画面から送信（押した瞬間に会話に出ます）、/ でコマンドやスキルを実行、停止、圧縮。Claude が選択肢で質問してきたら、ボタンで答えられます。

準備する

最初に 1 回だけ行います。コマンドはどのフォルダで実行してもかまいません（cd ~/fogcast は不要です）。

  1. 必要なものを確かめる

    Node.js は 18 以上、Claude Code は 2.1.290 以降が必要です。

    node -v && claude --version
  2. zip を解凍して、ホームフォルダに置く

    ダウンロードフォルダにある場合は、次のコマンドで ~/fogcast ができます。

    unzip ~/Downloads/fogcast-0.5.1.zip -d ~

    Finder でダブルクリックして、できた fogcast フォルダをホームフォルダに移してもかまいません。中にある .claude-plugin は見えないフォルダなので、中身だけを選ばずにフォルダごと移してください。

  3. マーケットプレイスとして追加する
    claude plugin marketplace add ~/fogcast
  4. インストールする
    claude plugin install fogcast@fogcast

    ユーザー全体に入るので、どのフォルダ、どのターミナルで起動した claude にも入ります。

  5. claude を起動し直す

    動いているセッションには途中から入りません。一度終了して、作業するプロジェクトのフォルダで claude を起動します。入力欄の下に Fogcast ch.1 … と出れば準備完了です。

  6. 画面を開く
    /fog

    ブラウザで画面が開きます。/fog の結果の下には鍵つきの URL（#k= 付き）も 1 行で出るので、開かなかったときはそれを押してください（VS Code のターミナルなら Ctrl+クリック）。2 回目からは同じブラウザで http://127.0.0.1:4317 を開くだけで使えます。

ご注意~/fogcast は、インストールしたあとも Claude Code が起動のたびに読み込みます。消したり、別の場所に移したりしないでください。

お知らせインストールせずに試すだけなら、claude --plugin-dir ~/fogcast で起動します。そのセッションだけで有効です。

Windows で WSL を使っているとき

Claude Code を WSL の中で動かしているなら、上の手順をすべて WSL のターミナルで行います（VS Code なら、左下が「WSL」になっているウィンドウのターミナル）。違うのは次の 4 つです。

ところWSL では
置き場所WSL の中のホームフォルダ /home/<WSLのユーザー名>/fogcast に置きます（echo ~ で出る場所の中）。Windows 側のフォルダ（C:\Users\…）には置きません。エクスプローラーからは \\wsl.localhost\Ubuntu\home\<WSLのユーザー名> に見えます（Ubuntu の部分はディストリの名前）。
zip の場所Windows のダウンロードフォルダは、WSL からは /mnt/c/Users/<Windowsのユーザー名>/Downloads です。名前は ls /mnt/c/Users で確かめられます。unzip が無いときは sudo apt install unzip で入れます。
Node.jsWSL の中に 18 以上が必要です。Ubuntu 22.04 の apt で入るものは 12 で古いので、nvm などで LTS 版を入れます。
画面Windows のブラウザで見ます。/fog で Windows の既定のブラウザが開きます（0.1.2 から）。WSL2 は localhost を Windows に転送するので、http://127.0.0.1:4317 で届きます。
unzip "/mnt/c/Users/<Windowsのユーザー名>/Downloads/fogcast-0.5.1.zip" -d ~

お知らせWindows のブラウザでつながらないときは、PowerShell で wsl --shutdown を実行してから WSL を開き直すと直ることがあります。

使いかた

チャンネルを増やす

VS Code で新しいターミナルを開き、claude を起動するだけです。自動で ch.2、ch.3… として並びます。同じリポジトリで並行して作業するときは、git worktree で作業フォルダを分けるとファイルの変更がぶつかりません。

見る

0 で全チャンネル、1〜9 でそのチャンネル。タイルや番組表の帯を押しても開きます。

会話はメッセージアプリと同じ並びです。あなたの依頼は右の黄色い吹き出し（「ターミナルから」「この画面から」と、どこから送ったかの印つき）、Claude の返答は左の白い吹き出しで、そのあいだの黒い枠に道具の呼び出しが並びます。ターンの頭の見出し（ターン番号・時刻・依頼の 1 行目）を押すと「たたむ ▴」「ひらく ▾」で開け閉めできます。今のターンと、その前の 2 ターンは開いたままで、それより前のターンは新しいターンが始まると自動で畳まれます。手で開け閉めしたターンは、そのままにします。

1 ターンは、あなたが 1 回送ってから、Claude が返答し終えて入力待ちに戻るまでです。道具の呼び出し、承認、Claude からの質問への回答は、そのターンの中に入ります。返答が終わってから送った修正は、次のターンになります。Claude の作業中にターミナルで送った修正は、Claude Code が作業の区切りで Claude に渡すので、同じターンの中に「作業中にターミナルから」の吹き出しで出ます（Claude がもう最後の返答を書いているときは区切りがないので、返答のあとに次のターンとして始まります）。

送る

送信欄に書いて Enter（改行は Shift+Enter）。そのターミナルで入力したのと同じ扱いです。送った文は押した瞬間に会話のいちばん下に出て、ターミナルに渡ると「まもなく始まります」、Claude が作業中なら「順番待ち · 今の作業が終わると始まります」と出ます。ターンが始まると、そのターンの吹き出しに置き換わります。送れなかったときは赤くなり、「もう一度送る」「消す」が出ます。ほかの画面（スマホなど）から送ったものも、同じように並びます。

次の入力の提案

Claude Code は返答のあと、入力欄に「次はこれを打つとよさそう」という文を薄く出します。同じ文が、空の送信欄にも薄く出て、下の行に「次の提案」として並びます。Tab（または →）か「入れる（Tab）」で送信欄に入ります（送るのは Enter を押したときです）。ターミナルで何か打つか、次のターンが始まると消えます。

コマンドを実行する

/ を押すと、そのターミナルで使えるコマンド（組み込み・スキル・プラグイン・MCP）の一覧が出ます。コマンドを選ぶと、送信欄の下にそのコマンドの引数（例 /effort [low|medium|…]）が、ターミナルと同じ書き方で出ます。一覧の右には、この画面から実行したときにどうなるかが出ます。

  • この画面で選ぶ：/resume・/model・/effort。この画面に選ぶ画面が開きます（下の 2 つの項目）。
  • 結果を表示：/context・/rename・/plan など。結果がこの画面の会話の欄に出ます。
  • ターンを始める：スキルと、/init・/code-review・/simplify など。Claude が作業を始めます。
  • ターミナルで開く：/usage・/status・/config など選択画面のあるもの。選択画面はターミナル側に出ます。
  • ターミナルで打つ：/recap など、Claude Code が本人がターミナルで打ったときだけ実行するもの。この画面からは送りません。

/clear は確認してから実行します。作業中に実行したコマンドは、今のターンが終わってから実行します。ターミナルで打ったコマンドも、その結果の 1 行（「Set effort level to high」など）がこの画面に出ます。

前の会話に戻る（/resume）

/resume を選ぶと、そのチャンネルのフォルダで前に話した会話の一覧が出ます（名前か最初の依頼、いつ、大きさ、最後の依頼）。言葉で絞り込めます。「再開」を押すと、ターミナルで /resume したのと同じく、そのチャンネルが選んだ会話の続きになります。チャンネルは終わらずにそのまま続き、会話の欄には「前の会話を再開しました」と、その会話の最後の 20 往復までが出ます。それまでの会話は残っていて、同じ一覧からまた戻れます。ターミナルで /resume したときも、同じように出ます。

  • 一覧は、/resume を開いたときに Claude Code の会話のファイル（~/.claude/projects の中）の最初と最後だけを読んで作ります。Fogcast が会話を保存することはありません。
  • ほかのターミナルで開いている会話は「ch.2 … で開いています」と出て、選べません（2 つのターミナルが同じ会話に書き込まないように）。
  • ほかのフォルダの会話は、そのフォルダで起動したターミナルのチャンネルから戻れます。
  • 作業中に選ぶと、今のターンが終わってから切り替わります。

モデルと考える深さ（effort）

チャンネルの見出しのモデル名（例 Opus 5.5）と「effort」を押すと、選ぶ画面が開きます。/model・/effort を選んでも同じで、/effort high のように値を付けると、そのまま変えます。

  • モデル：一覧は、そのターミナルの /config のモデルの行と同じです。選ぶとその行で切り替えるので、確認なしで切り替わり、/model と同じく新しいセッションの既定にもなります。会話の途中で切り替えると、次の返答で新しいモデルが会話を最初から読み直すため、その 1 回は時間とトークンが多くかかります。
  • effort：ターミナルで /effort を実行したのと同じです。見出しには、Claude Code が最後の返答で使った値が出ます。
  • 作業中に選ぶと、今のターンが終わってから切り替わります。ターミナルで切り替えたときも、見出しと会話の欄に出ます。

Claude の質問に答える

Claude が選択肢で質問してくると（ターミナルに選ぶ画面が出るとき）、そのチャンネルに質問のカードが出て、タイルは「回答待ち」になります。選択肢を押すと答えになります。質問が 1 つで 1 つだけ選ぶものは、押した時点で送ります。いくつも選べるものや質問が複数あるものは、選んでから「答える」を押します。選択肢にないときは「ほかの答え」に書きます。

ターミナルの選ぶ画面も同時に開いていて、先に答えた方が使われ、もう一方は閉じます。画面から答えると、ターミナルにも「User answered Claude's questions」と答えが残り、Claude にはターミナルで答えたのと同じ形で渡ります。承認の設定（オン・オフ）に関係なく使えます。

止める・圧縮する

「停止」は今のターンを中断します。「圧縮」は会話を要約してコンテキストを空けます（作業中なら、ターンが終わってから）。

ステータス

FOGCAST の横の「Lv」を押すと、ステータス画面が開きます（Esc で戻ります）。0.3.0 を入れた日から数え始め、あなた全体の Lv、5 つの能力、今日の EXP、日ごとの EXP、記録（作業した日・連続日数・ターン・トークン・料金・使った道具の種類）が並びます。Lv が上がると、画面に一度だけ知らせます（ターミナルには出しません）。

  • 量：やり終えたターン 1 回で +10 EXP、トークン 1 万ごとに +1。1 日の上限はありません。
  • 習慣：その日はじめてターンをやり終えると +50。続けて作業した日は 1 日ごとに +10 ずつ上乗せ（+70 まで）。
  • 初めて：ツール・スキル・エージェント・MCP を初めて使うと +30。
  • Lv：Lv n から n+1 までに 100 × n EXP。最高は Lv 99。
  • 能力：調査（Read・Grep・Web 検索など）、構築（Edit・Write）、実行（Bash など）、段取り（サブエージェント・タスク・計画）、拡張（スキル・MCP）。道具を 1 回使うごとに 1 pt（サブエージェントは 3 pt、スキルは 2 pt）で、10・50・200・600・1500 pt でランク 1〜5。

天気予報

5 時間枠と週の枠の今の割合、今のペース、リセット時の予報、上限に届く時刻を出します。値は Claude の応答が返るたびに届くので、最初の応答のあとに出ます（API キーで使っている場合は使用枠がないので出ません）。

週のカレンダーは、これまでの日と今日に、その日に使った週の枠の割合が出ます。押すとその日の記録（週の枠・ターン数・トークン・料金、チャンネル別の内訳、よく使ったツールやスキル）が開きます。先の日は、今のペースでの天気だけです（1 日 9% 未満が晴れ、18% 以上が雨、上限に届く日が霧）。日ごとの記録は 0.2.0 から、受け皿が動いているあいだの分を 35 日ぶん残します。

コミュ

使ったツール・スキル・エージェント・MCP がカードになり、全セッション通算の使用回数でランクが上がります。カードを押すと右端の輪の画面になり、↑↓・ホイール・ドラッグで回して、Esc で戻ります。種類で絞り込めて、よく使う順・種類ごと・最近使った順・ランク順・毎回の負担が大きい順・名前順で並べ替えられます。

「このカードについて」には、スキルなら SKILL.md の description、エージェントなら定義ファイルの description が、改行も含めてそのまま出ます。Claude Code の一覧から読むもので、Claude のコンテキストは使いません（本文は読みません）。組み込みのエージェントとツールには、Fogcast の短い説明が出ます。

コミュに加わるのは、次のときです。

  • ツール：初めて使ったとき。
  • ローカルのスキルとエージェント（そのプロジェクトの .claude にあるもの）と MCP：読み込んだときに未使用（カードなし）で「一覧」に並び、初めて使ったときにカードが付きます。
  • グローバルのスキルとエージェント（~/.claude・プラグイン・組み込み）：呼び出されたときに初めて加わります。呼ばれないものは「スキル」のタブにだけ並びます。
  • カード：Claude 本体・Read・Edit・Bash・組み込みのエージェントなど決まった 22 個は大アルカナ。そのほかは初めて使った順に、種類ごとの組（スキルは金貨、エージェントは剣、MCP は聖杯、ツールは棒）から 14 枚ずつ配られ、それより後のものはカードなしで「一覧」に並びます。

スキル

選んでいるチャンネル（全チャンネルのときは全部）のスキルを、3 つのタブで出します。「使った」はこのセッションで呼び出された回数と時刻、「ローカル」はプロジェクトの .claude/skills、「グローバル」は ~/.claude/skills・プラグイン・組み込みのスキルです。ローカルとグローバルには、毎回のコンテキストに入る名前と説明のおおよそのトークン数も出ます。disable-model-invocation: true のスキル（/ から手で実行するだけのもの）は「手動のみ · 0」と出ます。実行するまで Claude には渡らないので、毎回のコンテキストを使いません。

新しく入れたスキルは、動いているセッションでは /reload-skills を実行するか、claude を起動し直すと読み込まれ、Fogcast もそのとき（ほかに 5 ターンごと）に読み直します。初めて呼び出されると「〜を初めて使いました」と出て、カードが配られます（ランク 1）。

詳細

コンテキストの内訳、起動時に読み込んだもの（CLAUDE.md・スキル（ローカル／グローバル）・エージェント・MCP）、ターンごとの増え方、変更したファイル、タスク、サブエージェント、続きから始めるコマンド。

終わったチャンネル

ターミナルを閉じたチャンネルや、報告が途絶えたチャンネルは「終了」になり、12 時間は画面に残ります。いらないものは、そのチャンネルを開いて送信欄の右の「チャンネルを消す」か、全チャンネルの見出しの「終了したチャンネルを片付ける」で、すぐ消せます（動いているチャンネルは消せません）。消えるのは画面の表示だけで、Claude Code のセッションは残ります。「＋ 追加」の過去のセッションから claude --resume … をコピーして、続きから始められます。報告が途絶えただけのターミナルが戻ってきたときは、新しいチャンネルとしてまた並びます。

5

画面から承認する

初期設定はオフで、ツールを実行する前の確認はターミナルで行います。オンにすると、その確認を画面でも許可・拒否できます。オンにするときは、ターミナルに出る合言葉を画面に入力して、ブラウザをつなぎます。

  1. 「設定」で「この画面から承認する」をオンにする

    テレビのいちばん下の右端にある「設定」から開きます（全チャンネルではヒントの行の右、チャンネルを開いているときは送信欄の下の右）。ボタンに、今オンかオフかが出ています。

  2. ターミナルで合言葉を見る

    つながっているすべてのターミナルの入力欄のすぐ上に、黄色い枠で出ます。入力欄の下のステータスラインにも出ます。どのターミナルの合言葉も同じです。

    ターミナル（表示例）
    ⏺ テストを直しました。
    Fogcast ブラウザ承認の合言葉4821-0937
    ブラウザの Fogcast の画面（設定 → ブラウザから承認）に入力してください。あと約 5 分で使えなくなります。心当たりがなければ [ 取り消す ]
    ここ
    >
    Fogcast ch.1 · 合言葉 4821-0937（Fogcast の画面に入力） · ctx 41% · 5h 44%
    ここにも
  3. 画面に入力して「つなぐ」

    ターミナルに「ブラウザとつながりました」と出れば、オンになっています。

  4. 承認待ちを画面で許可・拒否する

    承認待ちになると、画面のそのチャンネルに「許可」「拒否」が出ます。ターミナルの入力欄の上には「Fogcast の画面で承認を待っています」と出て、「ここで確認する」でいつでもターミナルの確認ダイアログに戻せます。

  • Claude からの質問（選択肢）への回答は承認とは別で、この設定に関係なく画面から答えられます（「使いかた」の「Claude の質問に答える」）。
  • 合言葉は 5 分間だけ使えます。期限が切れたときや 5 回間違えたときは、画面の「合言葉を出し直す」で新しいものを出します。
  • 心当たりのない合言葉が出たら、ターミナルの枠の「取り消す」を押してください。
  • 画面で 2 分応答がないとき、画面を閉じているとき、組織の設定で確認が必須になっているツールは、ターミナルの確認ダイアログで承認します。
  • 合言葉はターミナルの画面にだけ出て、Claude（モデル）が読む会話には入りません。
  • オフにするときは、「設定」のスイッチを切ります。つないだブラウザはすべて外れます。

コマンド早見表

Claude Code の中

コマンドすること
/fog画面をブラウザで開きます（WSL では Windows のブラウザ）。結果の下に鍵つきの URL も出て、押すとつながった状態で開けます。その URL はあなたの画面にだけ出て、Claude が読む結果の 1 行や会話の記録には入りません。

ターミナル（シェル）

コマンドすること
claude plugin marketplace add ~/fogcastFogcast のフォルダをマーケットプレイスとして追加します。
claude plugin install fogcast@fogcastインストールします（ユーザー全体）。
claude plugin update fogcast@fogcastフォルダを新しい版に入れ替えたあと、版を更新します。
claude plugin list入っているプラグインと、オン・オフを確かめます。
claude plugin disable fogcast@fogcast --scope local今いるプロジェクトだけでオフにします。
claude plugin enable fogcast@fogcast --scope localオフにしたプロジェクトで、オンに戻します。
claude --plugin-dir ~/fogcastインストールせず、そのセッションだけで試します。
node ~/fogcast/hub/hub.mjs --stop受け皿（画面のサーバー）をすぐ止めます。次に claude を起動すると、自動で起動します。

画面のキー

キーすること
0〜9チャンネルを切り替えます（0 は全チャンネル）。
/開いているチャンネルのコマンドの一覧を出します。↑↓ で選び、Enter で入れ、Esc で閉じます。/resume・/model・/effort は、この画面に選ぶ画面が開きます。
Enter / Shift+Enter送信 / 改行。
↑↓ Home Endカードの画面で輪を回します。ホイールとドラッグでも回ります。
Escカードの画面や設定を閉じます。

更新する・外す

新しい版に更新する

  1. 新しい zip で ~/fogcast を上書きする
    unzip -o ~/Downloads/fogcast-0.5.1.zip -d ~

    ファイル名は受け取った版に合わせてください。

  2. 版を更新する
    claude plugin update fogcast@fogcast
  3. 各ターミナルの claude を起動し直す

    前の版の受け皿が動いていたら、新しい版のターミナルが自動で止めて、新しい受け皿を起動します。

プロジェクトごとにオフにする

オフにしたいプロジェクトのフォルダで実行します。そのプロジェクトの .claude/settings.local.json に書かれ、ほかのプロジェクトはそのままです。

claude plugin disable fogcast@fogcast --scope local

外す

  1. アンインストールする
    claude plugin uninstall fogcast@fogcast
  2. マーケットプレイスから外す
    claude plugin marketplace remove fogcast
  3. 受け皿を止める
    node ~/fogcast/hub/hub.mjs --stop
  4. フォルダを消す

    ~/fogcast（本体）と ~/.fogcast（鍵と記録）を削除します。

困ったときは

こんなとき確かめること
合言葉がどこにも見当たらないそのターミナルの入力欄のすぐ上と、入力欄の下のステータスラインを見てください。出ていなければ、そのターミナルの claude を 0.1.1 以降にしてから起動し直したか（0.1.0 のまま動いているターミナルには、通知で 1 分ほど出るだけです）、5 分たっていないかを確かめ、画面の「合言葉を出し直す」を押します。
入力欄の下に Fogcast が出ないインストールしたあとに claude を起動し直したか。claude plugin list で fogcast@fogcast が enabled か。そのプロジェクトでオフにしていないか。
Fogcast 未接続 のままnode -v で Node.js 18 以上が入っているか。node が PATH にないときは、環境変数 FOGCAST_NODE に node の場所を指定します。ポート 4317 を別のプログラムが使っているときは通知が出るので、FOGCAST_PORT で別の番号にします。
/fog でブラウザが開かない/fog の結果の下に出る鍵つきの URL（#k= 付き）をブラウザで開いてください。WSL では Windows の既定のブラウザを開きます（0.1.2 から）。2 回目からは同じブラウザで http://127.0.0.1:4317 だけで開けます。
画面は開くのに、ターミナルの様子が映らない画面に「まだこの画面はつながっていません」と出ていれば、鍵のない URL（http://127.0.0.1:4317 だけ）で開いた、初めてのブラウザです。ターミナルで /fog を実行するか、/fog の結果の下に出る鍵つきの URL を開いてください。鍵はブラウザに保存されるので、次からはアドレスだけで開けます。127.0.0.1 と localhost は別のアドレスとして扱われるので、いつも同じ方で開いてください。ターミナルの入力欄の下が Fogcast 未接続 のときは、上の「Fogcast 未接続 のまま」を見てください。
承認の「許可」「拒否」が画面に出ない「設定」で「オン · このブラウザとつながっています」になっているか。組織の設定で確認が必須のツールは、ターミナルでだけ承認できます。
画面に「ui.html が見つかりません」~/fogcast を動かしたり消したりしていないか。フォルダを戻してから node ~/fogcast/hub/hub.mjs --stop を実行し、claude を起動し直します。
チャンネルに「報告が途絶えました」そのターミナルが閉じたか、20 秒以上応答がありません。ターミナルが動いていれば、すぐ元に戻ります。
終わったチャンネルを消したいそのチャンネルを開いて「チャンネルを消す」、またはまとめて全チャンネルの見出しの「終了したチャンネルを片付ける」。セッションは残るので、「＋ 追加」の過去のセッションから続きを始められます。
送った文が「順番待ち」のままClaude が作業中のターミナルは、今のターンが終わってから始めます。急ぐときは「停止」で今のターンを止めます。ターミナルが終了すると「送れませんでした」になり、「もう一度送る」か「消す」を選べます。
質問のカードが出ないClaude が選択肢の画面で質問したとき（AskUserQuestion）に出ます。返答の文章の中で「1. A案 2. B案」のように聞いているときはカードになりません。送信欄に答えを書いて送ってください。ツールを使ってよいかの確認は承認で、「設定」から画面でも許可・拒否できるようにできます。
新しく入れたスキルが出ない動いているセッションには、/reload-skills を実行するか claude を起動し直すまで入りません。グローバルのスキルは、呼び出されるまでコミュには出ません（「スキル」のタブの「グローバル」には出ます）。
カレンダーの日付を押しても「記録はありません」日ごとの記録は 0.2.0 から、受け皿が動いているあいだの分だけを残します。それより前の日は、使った割合だけが出ます。
画面を閉じたり、PC を再起動したりすると記録は消える？ブラウザの画面を閉じても、受け皿が動いているあいだは会話も数字もそのままで、開き直せば元どおりです。日ごとの記録（カレンダー）・ステータス（Lv・能力・記録）・コミュの回数・使用枠の読み取り・終わったセッションの再開コマンドは ~/.fogcast/state.json に保存されるので、受け皿が止まっても、PC を再起動しても残ります。会話の本文とチャンネルごとの数字は受け皿のメモリにだけあるので、受け皿が止まると消えます（動いているターミナルの分は、つながり直したときに送り直されます）。その日の合計は、カレンダーの「今日」で見られます。
Lv が上がらない、ステータスが出ないEXP は、ターミナルの Fogcast が受け皿につながっているあいだの、やり終えたターン・作業した日・初めて使った道具から入ります。途中で止めたターンは量に数えません。数え始めは 0.3.0 を入れた日からです。FOGCAST の横に「Lv」が出ていないときは、画面がまだ受け皿につながっていません。
天気予報が出ない最初の応答が返ってから出ます。API キーで使っている場合は、使用枠がないので出ません。
9

安全と仕様

安全について

  • 受け皿は 127.0.0.1 だけで待ち受け、ほかのホスト名やほかのサイトからの呼び出しは断ります（DNS リバインディング対策を含みます）。
  • 画面と Mod は ~/.fogcast/token の鍵で受け皿とやりとりします（本人だけが読めるファイル）。鍵は URL の # の後ろで画面に渡すので、サーバーのログや Referer には残りません。
  • 画面からの承認は初期設定でオフです。オンにしても、ターミナルにだけ出る合言葉を入れたブラウザしか承認できません。
  • 鍵を持つと画面と同じことができます。Claude に ~/.fogcast を読ませたり、127.0.0.1:4317 へ送信させたりする操作は許可しないでください。

仕様

版0.5.1
必要なものClaude Code 2.1.290 以降（Mod が使える版）、Node.js 18 以上
日付の区切り画面（ブラウザ）の時計に合わせます。WSL の時計が Windows と違う地域になっていても、カレンダーと連続日数は画面の日付で数えます（0.3.0 から）。
確かめた環境Linux。WSL は、Windows のブラウザを開くところを Linux 上で見立てて確かめました。macOS とネイティブの Windows はまだ確かめていません。
画面http://127.0.0.1:4317（この説明書は /guide）
コンテキストへの影響毎回のコンテキストに足すものはありません（claude plugin details で約 0 トークン）。増えるのは、コマンドの一覧の /fog 1 行と、/fog を実行したときの結果 1 行だけです。読み込んだスキル・エージェント・MCP の一覧と、スキルやエージェントの説明、コマンドの引数、次の入力の提案は、Claude Code の手元の情報から読むだけで、モデルには送りません。画面から答えた質問は、ターミナルで答えたときと同じ答えとして Claude に渡ります。
受け皿の終了ターミナルも画面もつながっていない状態が 20 分続くと、自動で終わります。次に claude を起動すると、自動で起動します。
保存するもの~/.fogcast/ に、鍵（token）、state.json（コミュの使用回数と最近の使用（カードごとに直近 20 回の、依頼の書き出しや道具の入力の要約）、使用枠の読み取り、日ごとの記録（ターン数・トークン・料金、チャンネル名ごとの内訳、使ったものの回数。35 日ぶん）、ステータス（EXP・能力・記録）、終わったセッションの再開 ID と最初の依頼の書き出し）、hub.log。会話の本文（返答や道具の結果の全文）と、送ってまだ始まっていない文は受け皿のメモリにだけ置き、ファイルには書きません。
読むものClaude Code の会話のファイル（~/.claude/projects/…/<セッション ID>.jsonl）は、/resume の一覧を開いたとき（各ファイルの最初と最後だけ）と、会話を再開したとき（その会話の最後の部分）にだけ読みます。読むのは、そのチャンネルのフォルダの会話だけです。
